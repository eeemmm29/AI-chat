# Vibe Coding Final Project: Chat Website

## Goal

Build a working chat website with a **Python FastAPI backend**. You may use any AI tools to help you build, debug, design, and deploy the project.
- Use Any AI tools (ChatGPT, Cursor, Copilot, Claude, Gemini, etc.)

This is a **speed-building project**.
You are evaluated on:
- how efficiently you use AI tools,
- how quickly you build,
- and how complete your product is.

---

## Required Features

Your chat app must include:

1.  **User Management**
    - Add/register a user
    - Search users
    - Show list of users
2.  **Messaging**
    - Send messages
    - Receive messages
    - Show chat history
    - Search messages
    - Show messages by user or conversation
3.  **Frontend**
    - Simple website interface
    - Input box for sending messages
    - User list or search box
    - Chat window
    - Clean basic design
4.  **Backend**
    - Use Python FastAPI
    - Create API endpoints for users and messages
    - Store data in a database or file
    - API should be testable
5.  **Deployment**
    - Deploy the project to any cloud platform, for example:
        - Render
        - Railway
        - Fly.io
        - Google Cloud
        - AWS
        - PythonAnywhere
        - Any other working cloud
6.  **Additional Features Examples:**
    - Dark mode
    - Emoji support
    - Image upload
    - Typing indicator
    - Online/offline status
    - Group chat
    - AI chatbot
    - AI message suggestion
    - AI translation
    - Delete/edit message
    - Docker
    - Profile pictures
    - Notifications
    - Responsive/mobile UI
7.  **GitHub**
    - Create a GitHub account if you do not have one
    - Create a public GitHub repository
    - Upload your full project code
8.  **Demo Video**
    - Create a short 2–3 minute video
    - Show:
        - Your website
        - Main features
        - Sending and receiving messages
        - Backend/API if possible
        - Deployed live link
    - Upload the video to YouTube
9.  **README.md**
    - Your README file must include:
        - Project title
        - Short description
        - Features list
        - Tech stack
        - How to run locally
        - Live website link
        - YouTube demo video link
        - Screenshots if possible
